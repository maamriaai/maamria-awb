## Efficient Prompting Guide

**Always include the file path in your prompt.**
Vague: "fix the login bug" — forces Claude to explore many files.
Specific: "fix the login bug in `src/auth/login.py` — the `/login` endpoint returns 500 on uppercase emails" — Claude reads one file.

**One task at a time.**
Asking Claude to do two things at once accumulates context from both. Do them sequentially with `/compact` between them.

**Use `/compact` after heavy tasks.** After any task that read 5+ files, run `/compact` before the next one.

**Use `/clear` between unrelated tasks.** Switching features? Clear the context entirely.

**Never ask "explain how X works in this project."** This forces Claude to read 10+ files. Ask about one layer at a time.
